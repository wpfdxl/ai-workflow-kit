# 接口文档 Review

> 人 review `02_接口文档.md`（及 `docs/<需求>/`）。全过才进阶段④。无对外 API 时只确认「无独立接口」与方案第 4 节一致即可。

## A. 完整性
- [ ] 接口清单与开发方案第 4 节一致
- [ ] 每个接口都有：路径、参数表、业务规则、返回字段、返回示例
- [ ] 多端路径分开列

## B. 参数
- [ ] 类型 / 必填 / 说明
- [ ] 格式约束（日期、枚举、长度）
- [ ] 默认值 / 空值行为

## C. 返回字段
- [ ] 类型清楚
- [ ] 枚举列全
- [ ] 嵌套结构画清
- [ ] 每个字段有说明（含嵌套）

## D. 返回示例
- [ ] 正常
- [ ] 空态 / 无数据
- [ ] 边界
- [ ] 错误（如有业务错误码）

## E. 业务规则
- [ ] 排序
- [ ] 过滤
- [ ] 特殊展示
- [ ] 文案由后端还是前端生成

## F. 命名与格式
- [ ] 路径 / 方法名符合本仓约定
- [ ] md 可读
- [ ] `docs/` 文件（若有）与 md 字段一致，格式符合 `project.local.md`
