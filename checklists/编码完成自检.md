# 编码完成自检

> 全部 Task 完成后逐条确认。不过 → 修 → 再跑。语言细节以目标仓规范和 `project.local.md` 为准。

## A. 分层与调用
- [ ] 入口只调业务层，不直连存储
- [ ] 跨模块走对方业务层
- [ ] 分层目录 / 命名跟本仓惯例一致

## B. 命名
- [ ] 对内命名跟本仓风格一致
- [ ] 对外路径 / 方法名跟定稿 02 一致
- [ ] 未与现有功能撞名

## C. 类型与注释
- [ ] 方法注释足以让下一任看懂入参出参
- [ ] 按本仓要求做了类型约束 / 校验

## D. 缓存（无则勾「无」）
- [ ] 无缓存，或 key / 过期 / 失效符合方案第 6 节
- [ ] 未使用本仓已淘汰的缓存 API

## E. 存储
- [ ] 读写走本仓规定的连接（主从、事务边界）
- [ ] 自动维护字段未在代码里乱写（若本仓由 DB 维护时间戳）
- [ ] 未用保留字当字段名

## F. 风格
- [ ] 跟邻近文件风格一致
- [ ] 未引入方案没有的动态调用、隐式魔法

## G. 日志与事务
- [ ] 一致性关键点有 log
- [ ] 跨库 / 跨服务有可恢复线索
- [ ] 事务内无非必要耗时

## H. 最小修改
- [ ] 没格式化无关代码
- [ ] 没重构未提及部分
- [ ] 没引入降级性改动

## I. 对齐契约
- [ ] 入参 / 返回与 `02_接口文档.md` 一致
