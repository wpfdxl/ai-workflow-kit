# Publishing as a standalone open-source repo

This folder is self-contained. To publish:

1. Copy `ai-workflow-kit/` to a new git repository (or `git subtree split` / move history as you prefer).
2. Replace `<this-repo-url>` in `README.md` with the real clone URL.
3. Adjust `LICENSE` copyright holder if needed.
4. Push and enable Issues / Discussions as you like.

Do **not** copy sibling personal workspaces (`workspace/` demands from other trees) into the public repo.

Suggested first public contents: everything under this directory as-is (samples + docs + viewer).
