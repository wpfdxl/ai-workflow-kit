# 入门指南

## 推荐：Clone 后用一句话让 AI 初始化

1. 克隆本仓库，用 AI IDE **打开本 kit 目录**
2. 把 [`bootstrap/init_接入我的项目.md`](../bootstrap/init_接入我的项目.md) 整段提示词发给 AI，填上你的语言/框架/`code_root`
3. AI 会生成你的 `profiles/<id>/`、改 `PROJECT.md`，并**删掉无关示例**（sample profile、`_example_*`、对应 doc）
4. 对照 [`哪些可以删.md`](哪些可以删.md) 验收；完整对话范例见 [`示例对话_初始化.md`](示例对话_初始化.md)

初始化完成后，目录里应只剩工作流本体 + **一份**你的 profile（见「哪些可以删」文末示意）。

## 1. 放置本仓库

可放在业务仓旁或子目录，**不必**与业务代码同一套规范文件混写。编码时靠 `PROJECT.md` → `code_root` 指向真实代码。

## 2. 选定或生成规范

- **接入工程（推荐）**：`bootstrap/init_接入我的项目.md`（生成规范 + 清理示例）
- **只生成规范**：`bootstrap/step0_生成项目规范.md`
- **手改**：编辑 `PROJECT.md` 的 `active_profile` / `rules_path` / `code_root`

## 3. 开一个需求

初始化后不要再依赖 `_example_*`（默认已删）。直接：

```bash
mkdir -p workspace/订单导出 doc/订单导出
cp workspace/_templates/00_需求模板.md workspace/订单导出/00_需求.md
# 同样复制 01~03 模板并改标题；写 STATUS.md；INDEX 登记
# 需求名与 doc/<需求名>/ 保持一致（中文）
```

或让 AI：「按模板新建需求「订单导出」并填 00_需求.md」。

## 4. 四阶段

| 阶段 | 动作 |
|---|---|
| ① | `_prompts/step1_生成开发方案.md` → `01_开发方案.md` |
| ② | 人肉过 `_checklists/开发方案review清单.md` |
| ③ | `_prompts/step2_生成接口文档.md` → `02` + `doc/<需求>/*.json` |
| ④ | 填好 `03_编码任务.md` 的 `@`，跑 `step3_执行编码.md`，再跑通用自检 + profile 自检 |

规范**只**认 `PROJECT.md` 指向的 profile。

## 5. 预览接口文档

```bash
cd doc
python3 sbdoc_web.py --port 9122
```

## 6. 归档

`workspace/<需求>` 与 `doc/<需求>` 一并搬到 `archive/` 与 `doc/archive/`，更新 `INDEX.md`。

## 7. 多需求并行

`INDEX.md` 登记涉及文件；有交集则分支隔离或串行编码。

## Cursor

`.cursor/rules/workflow.mdc` 约束走本流程；你的栈细则以 active profile 为准（init 时可再生成 `<profile_id>.mdc` 摘要）。
