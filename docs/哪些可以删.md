# 初始化后：哪些保留 / 哪些可删

接入真实工程并生成**你自己的** `profiles/<id>/` 之后，按下面清理。  
用 [`bootstrap/init_接入我的项目.md`](../bootstrap/init_接入我的项目.md) 时，AI 应自动按「可删」列清理。

## 必须保留（工作流本体）

| 路径 | 作用 |
|---|---|
| `PROJECT.md` | 当前 profile + code_root |
| `.cursor/rules/workflow.mdc` | 打开本目录时约束 AI 走本流程 |
| `bootstrap/` | step0 / init 提示词、RULES 模板 |
| `workspace/_templates/` | 00~03 模板 |
| `workspace/_prompts/` | step1~3 |
| `workspace/_checklists/` | review / 自检 |
| `workspace/INDEX.md` | 多需求协调（可清空表格内容） |
| `doc/sbdoc_web.py` | 接口文档预览 |
| `doc/hfdoc_config.json` | Viewer 配置 |
| `doc/archive/`、`archive/` | 归档落点（可空） |
| `docs/` | 说明文档 |
| `profiles/<你的id>/` | **你的**规范包 |
| `README.md` / `LICENSE` / `CONTRIBUTING.md` | 仓库元信息 |

## 初始化后建议删除（开箱示例）

| 路径 | 原因 |
|---|---|
| `profiles/*-sample/` | 演示用其它技术栈，与你的工程无关 |
| `workspace/_example_健康检查摘要/` | 演示需求 |
| `workspace/_example_用户资料查询/` | 演示需求 |
| `doc/健康检查摘要/` | 演示接口 json |
| `doc/用户资料查询/` | 演示接口 json |

> 若你还想对照学习，可暂时只删不相关栈的 sample，保留与你最接近的一个 `*-sample`；默认推荐**全删 sample**，只留自己的 profile。

## 不要删错

- 不要删 `_templates` / `_prompts` / `_checklists`（没有它们就无法跑四阶段）
- 不要删 `sbdoc_web.py`（除非你确定不用预览）
- 正式需求目录是 `workspace/<需求名>/`（**没有** `_example_` 前缀），初始化时还不存在，无需删

## 清理后目录应长这样（示意）

```
ai-workflow-kit/
├── PROJECT.md                 # 已指向你的 profile + code_root
├── bootstrap/
├── profiles/
│   ├── README.md
│   └── <你的profile>/         # 仅此一份规范
├── workspace/
│   ├── _templates/ _prompts/ _checklists/
│   └── INDEX.md               # 表为空
├── doc/
│   ├── sbdoc_web.py
│   ├── hfdoc_config.json
│   └── archive/
├── archive/
└── docs/
```
