# PHP 5.5 + ThinkPHP 风格（示例规范）

> 示意用。通用 PHP 5.5 + ThinkPHP 3.x 风格分层示范，非某一业务仓的正式规范。

## 1. 技术栈

- 语言与版本：PHP 5.5（无 `??`、无 `::class` 常量取名等更高语法）
- 框架与版本：ThinkPHP 3.x 风格模块化
- 运行时/包管理：按目标仓现有方式
- 主要依赖约定：以目标仓已有封装为准

## 2. 仓库与目录

- 代码根目录习惯：`Application/<Module>/`
- 模块/包划分：Controller / Logic / Db(Table) / Cache / Constants
- 配置文件位置：模块或公共 Conf
- 测试目录：按目标仓；无强制

## 3. 分层架构

| 层 | 职责 | 允许依赖 | 禁止 |
|---|---|---|---|
| Controller | 参数校验、调 Logic、返回 | Logic | 直接调 Table/Cache |
| Logic | 业务、事务 | Table、Cache、其他 Logic | 暴露 SQL 细节给 Controller |
| Table | 单库表访问 | Db 封装 | 业务分支堆砌 |
| Cache | 缓存读写 | Logic 取数（不直连 Table） | 业务规则 |
| Constants | 常量与映射数组 | 无 | 写方法 |

- 跨模块调用约定：走对方 Logic
- 事务放在哪一层：Logic

## 4. 命名规范

- 文件/目录：类名与文件名对应（目标仓习惯）
- 类型/类：大驼峰
- 函数/方法：小驼峰；Table 方法以 `Db` 结尾；Cache 方法以 `Cache` 结尾
- 变量：小驼峰
- 常量：大写下划线
- 对外 HTTP：小写下划线；页面 `_page`，GET `_get`，POST `_post`
- DB 表/字段：小写下划线；避免保留字作字段名

## 5. API 约定

- 路由组织：按模块 Controller 方法
- 鉴权：按目标仓
- 统一响应：`status` / `msg` / `data` 类包装（以目标仓为准）
- 错误码：常量集中定义
- 分页：page + page_size（或目标仓既有字段）

## 6. 数据访问

- ORM / 查询封装：目标仓 Db 封装
- 读写分离：读从库、写主库（若封装支持）
- 迁移/DDL：单独 SQL 文件评审
- 禁止：N+1；保留字字段名

## 7. 缓存（如有）

- 客户端封装：目标仓 Redis 封装
- key 命名：前缀常量 + 业务 id
- 过期与失效：写路径删缓存或短 TTL
- 禁止：无约定的散落魔法字符串 key

## 8. 日志与可观测

- 关键失败、跨库、补偿必记日志
- 禁止日志打密码、token 明文

## 9. 代码风格与禁止项

- 禁止：三目、无花括号 if、动态方法调用（业务代码）
- 注释：复杂分支写 why；方法补 @param/@return
- PHP 5.5 语法上限

## 10. 修改原则

- 最小修改；不格式化无关代码
- 不主动大重构，除非任务要求

## 11. 编码顺序（摘要）

Table → Logic → Cache → Controller → 接口文档 / 自检

## 12. Review 关注点

- 分层是否穿层；命名后缀；PHP 语法版本；缓存一致性
