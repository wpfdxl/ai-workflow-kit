## 3. 需求描述

App 启动后请求单个功能开关。服务端从配置存储读取，未配置视为关闭。

## 4. 功能点拆解

- [x] 按 key 查询开关
- [x] 未知 key 返回关闭，不报错

## 5. 输入输出预期

- 关键入参：`key`（非空字符串）
- 关键返回字段：`key`、`enabled`（bool）
- 特殊展示规则：无前端文案

## 6. 验收标准

- [x] 已配置且为开 → `enabled: true`
- [x] 未配置或为关 → `enabled: false`
