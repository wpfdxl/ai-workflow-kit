## 1. 文档说明

- 模块：health
- 数据来源：进程配置
- 适用端：Web / 内部
- 鉴权：无
- 返回说明：业务在 `data`

## 2. 接口清单

- `GET /api/v1/health`：健康摘要

## 3. 健康摘要 GET /api/v1/health

### 3.1 请求

`GET /api/v1/health`

参数：无

### 3.2 业务规则

- 无需登录
- status 固定字符串 `ok`（示例）

### 3.3 返回字段

| 字段 | 类型 | 说明 |
|---|---|---|
| code | int | 0 成功 |
| message | string | 提示 |
| data.status | string | 固定 ok |
| data.version | string | 应用版本 |
| data.time | string | UTC ISO8601 |

### 3.4 返回示例

#### 正常
```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "status": "ok",
    "version": "1.0.0",
    "time": "2026-08-04T02:00:00Z"
  }
}
```

#### 空态

不适用（始终有 data）

#### 错误
```json
{
  "code": 500,
  "message": "version not configured",
  "data": null
}
```
