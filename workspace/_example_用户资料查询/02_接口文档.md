## 1. 文档说明

- 模块：user
- 数据来源：users
- 适用端：gRPC / HTTP
- 鉴权：按目标仓（示例：内网可调）
- 返回说明：gRPC 以 proto 字段为准；HTTP JSON 字段同名 snake 或按生成器约定（示例子段用 snake_case）

## 2. 接口清单

- `GetUserProfile`：`GET /v1/users/{user_id}/profile` / gRPC `user.v1.User/GetUserProfile`

## 3. 获取用户资料 GetUserProfile

### 3.1 请求

HTTP：`GET /v1/users/{user_id}/profile`

gRPC：`rpc GetUserProfile (GetUserProfileRequest) returns (GetUserProfileReply)`

参数：

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| user_id | int64 | 是 | 用户 ID，必须 >0 |

### 3.2 业务规则

- user_id ≤ 0 → 参数错误
- 用户不存在 → reason=`USER_NOT_FOUND`
- status：1 正常，2 冻结

### 3.3 返回字段

| 字段 | 类型 | 说明 |
|---|---|---|
| user_id | int64 | 用户 ID |
| nickname | string | 昵称 |
| avatar_url | string | 头像 URL，可能为空串 |
| status | int32 | 1 正常 / 2 冻结 |

### 3.4 返回示例

#### 正常
```json
{
  "user_id": 10001,
  "nickname": "alice",
  "avatar_url": "https://cdn.example.com/a.png",
  "status": 1
}
```

#### 空态（不存在）
```json
{
  "code": 404,
  "reason": "USER_NOT_FOUND",
  "message": "user not found"
}
```

#### 错误（参数）
```json
{
  "code": 400,
  "reason": "INVALID_ARGUMENT",
  "message": "user_id must be > 0"
}
```
